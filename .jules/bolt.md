## 2024-03-21 - [O(N^2) Array Deduplication in React]
**Learning:** Found multiple instances of `.filter((val, idx, self) => idx === self.findIndex(...))` in frontend/src/components/dashboard/TradingChart.tsx. This creates an O(N^2) bottleneck, especially on frequent re-renders with large charting datasets, as `findIndex` iterates the array for every element. Also, using multiple `.map().filter()` chains over the same array is inefficient compared to aggregating them into a single loop.
**Action:** Replace `.filter()` + `.findIndex()` with an O(N) `Set` and a single `for...of` loop for deduplication in high-frequency/large-dataset React components. Collapse multiple `.map().filter()` passes into a single iteration block when mapping different fields from the same source.
