## $(date +%Y-%m-%d) - [Optimize RSI Pandas Rolling Overheads]
**Learning:** Found a significant overhead in `compute_rsi` where Wilder's smoothing was being implemented using full `df.rolling(window).mean()` followed by iterative Pandas `.iloc` assignments inside a loop. The combination of full rolling allocation (when only the first SMA was needed for the seed) and Pandas Series indexing within a hot loop resulted in high overhead (~15s per 1000 calls).
**Action:** Extract the raw arrays using `.values`, calculate the initial SMA using `np.mean` just for the required slice, and then use a scalar variables (`curr_gain`, `curr_loss`) inside a python loop to compute the exponential smoothing. This yielded ~18-20x speedup while preserving exact functionality. Always avoid Pandas `df.iloc` and `df.rolling` in iterative mathematical algorithms where single values or seeds are sufficient.
